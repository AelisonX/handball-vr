# Handball VR - The Courtyard

Early Quest VR and desktop playtest build.

Play: https://aelisonx.github.io/handball-vr/

Open directly in Quest Browser, select Enter VR, then choose Wall practice or a CPU difficulty. Practice uses the full enclosed arena with the end and side walls. CPU mode offers Easy, Medium and Hard.

VR: move your hands to slap; hold trigger to make a fist; hold grip to grab and release to throw. A/X opens the menu. Left stick moves, right stick snap-turns.

Desktop: WASD moves, mouse positions the glove, left click slaps, right click punches, hold E to grab and release to throw, Space serves, P pauses.

The online versus client is included, but no public room/signaling service is configured for this playtest. Use practice or CPU mode for now.

Prototype v0.1.0: 23 non-network automated checks and the TypeScript/Vite production build passed. Physical Quest testing, controller feel and connected multiplayer remain to be verified.

This repository currently contains the standalone production build. Development source and local testing files remain in the separate local project. No certificates, credentials or diagnostic logs are included.

Built as a separate game using selected systems from Bean There VR. Bean There VR and its hosting were not modified.
